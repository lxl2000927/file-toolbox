## 行为边界

- 暂停和取消在安全的页面/输出边界响应，当前原生 OCR 调用需要先结束。
- 工作区保存当前编辑结果，不恢复撤销栈；恢复后发起新导出需重新选择输出目录。
- 中断任务不会自动执行。手动续做会验证来源、输出目录及已完成文件；源文件变化时拒绝继续旧任务。
- 分卷能限制单个 PDF 的处理规模；选择单文件输出仍可能触发内存保护。任务恢复以已完整发布的输出单元为边界。
- 发布包未配置代码签名证书。本机安装验收脚本会拒绝覆盖已有安装或快捷方式，所有应用运行使用独立数据目录。
