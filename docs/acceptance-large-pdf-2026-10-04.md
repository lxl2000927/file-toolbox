# 3000 份 PDF 工作台验收

本轮针对导入和预览扩容，验证对象为当前工作区源码构建。没有发布安装包。

## 使用行为与边界

- 工作区最多 3000 份 PDF/图片、合计 100000 页；单文件最多 10000 页。桌面入口继续限制单 PDF 200 MiB、图片 15 MiB，渲染最多 3200 万像素。
- 每 16 份检查一批，只检查新加入文件，已完成批次立即显示。停止导入保留已载入文件；损坏、加密等失败项单独显示。
- 每组 12 页缩略图，预览请求只携带这些页涉及的来源；高清预览只请求一个文件。快速翻页取消旧请求并丢弃迟到结果。
- 缩略图 LRU 最多 120 项，字符串存储预算 16 MiB；撤销最多 40 步且历史快照合计限制 400000 个页引用。大工作区可撤销步数会相应减少。
- Python 在一次请求中最多打开一个来源文档；导入不再受旧的 768 MiB 总量限制。实际读取仍验证授权文件句柄和内容签名。
- PDF 输出直接写入临时文件流，成功后原子发布；同名文件不覆盖。最终合并文档本身仍占内存，合并、压缩和 OCR 的内存/耗时不能套用预览指标。

## 实测样例

脚本合成 3000 个独立 PDF，每份 3 页，合计 9000 页；其中 1000 份嵌有带纹理的模拟扫描图片，其余为文字页。总计 1,071,199,950 字节（约 1.07 GB）。1000 份子集约 358 MB。来源文件始终只读。

真实 Electron 主进程、preload、Vue 和 Python 引擎均参与；仅系统文件选择框返回合成样例路径，使用隔离用户目录。

| 桌面场景 | 1000 份 / 3000 页 | 3000 份 / 9000 页 |
| --- | ---: | ---: |
| 从点击导入到首组 12 张预览 | 0.404 秒 | 0.754 秒 |
| 全部导入完成 | 2.332 秒 | 6.313 秒 |
| 跳至末尾、12 张预览显示完成 | 0.373 秒 | 0.373 秒 |
| 返回首组缓存预览 | 0.326 秒 | 0.329 秒 |
| 测量期间渲染器长任务（>50 ms） | 0 | 0 |

预览计时包含页面切换动画完成；长任务指标只描述渲染器主线程，不代表所有进程或所有输入都不会等待。已检查连续跳页、始终仅渲染 12 张卡片、中途停止导入保留已载入页面、无渲染器错误，并保存截图。

独立 Python 进程中，3000 份检查耗时 1.929 秒，检查/单页预览阶段峰值工作集约 66.5 MiB（基线约 60.5 MiB）。这些是 Windows 工作集读数，不是整个应用内存；Python/原生库的私有提交读数也保存在报告中。

完整合并 3000 份为 9000 页 PDF 用时 14.275 秒，输出约 1.07 GB；核对页数和末页文字，峰值 Python 工作集约 1145.7 MiB。大规模输出的内存仍随最终文档内容增长。

这些数值来自本机合成样例及当前磁盘缓存状态，不能承诺任意复杂 PDF、网络盘、数万页 OCR 或其他硬件达到相同时延。

## 回归与证据

- Python：114 项通过；Node/Vue/Electron：59 项通过；类型检查、构建和原有 22 项桌面验收通过。
- `acceptance-samples/scale-evidence/desktop-scale.json`：真实桌面 1000/3000 份的计时、取消和错误记录。
- `acceptance-samples/scale-evidence/native-1000.json`、`native-3000.json`：Python 检查、预览、合并和内存读数。
- `acceptance-samples/scale-evidence/workspace-3000.png`：9000 页工作区末尾预览。
- `acceptance-samples/scale-results/`：可打开核对的真实合并结果。

```powershell
.venv\Scripts\python.exe scripts\create_scale_samples.py
.venv\Scripts\python.exe scripts\benchmark_pdf_scale.py 1000
.venv\Scripts\python.exe scripts\benchmark_pdf_scale.py 3000 --merge
cd electron-app
npm run build
npm run test:scale
```

样例输入和合并输出合计约 2.2 GB，全部位于被 Git 忽略的 `acceptance-samples` 下。压测不会读取或改写用户文档。
