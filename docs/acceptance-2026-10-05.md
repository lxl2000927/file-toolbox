# 2026-10-05 本地验收清单

本轮按已确定的八项 PDF 改进实施，验收对象为当前工作区源码运行版本。原有重命名、普通拆分、扫描拆分、更新和日志回归测试一并执行。没有发布或替换 GitHub 上的安装包。

## 启动

双击项目根目录 `start-toolbox.cmd`。它使用项目 `.venv` 和已构建的 Electron 主进程，自动复用或启动本地界面服务。等待窗口底部显示“已就绪”。

当前依赖已安装，中英文 OCR 语言数据已安装并通过 SHA-256 校验。修改主进程或 preload 后需要在 `electron-app` 目录重新执行 `npm run build`。

## 验收样例与步骤

样例位于项目根目录 `acceptance-samples`，全部由脚本合成。建议新建一个输出文件夹以便核对。

1. **合并、调整与撤销**：进入 PDF 工作台，依次添加 `01-front.pdf`、`02-back-reversed.pdf`。应显示 6 个缩略图。多选后旋转、前移/后移、拖动，执行撤销/重做；点击缩略图应打开大图。
2. **双面扫描排序**：展开“正反面交错合并”，勾选背面逆序并应用。导出页序应为 FRONT ONE、BACK ONE、FRONT TWO、BACK TWO、FRONT THREE、BACK THREE。
3. **导出与重名**：指定输出目录和名称，导出两次。同名文件自动编号，原文件不变。选择部分页面，使用“提取所选”核对输出页数。
4. **空白复核**：清空后添加 `04-blank-and-black.pdf`，查找空白页。应只标记第 2 页；第 3 页纯黑和第 4 页小字保留。选中候选、删除、撤销，应恢复 4 页。
5. **扫描复核**：在扫描拆分页选择 `03-scan-markers.pdf`，使用印章检测并全量扫描。应在第 1、3、5 页发现标记，进入复核工作区，形成 3 段；合并前两段后确认导出，应得到 2 份 PDF。扫描结束到确认之间不产生输出文件。
6. **手动修订标记**：在复核中增加或移除标记，观察分段与预计输出数量变化；撤销应恢复。返回参数、修改输入或识别参数后旧复核应失效，需要重新扫描。
7. **图片和 OCR**：工作台添加 `05-chinese-scan.png` 或 `06-chinese-scan.pdf`，选择“离线 OCR”。导出的 PDF 应能搜索“文件工具箱”“Invoice”“12345678”；识别结果页也能展开文字。`07-hybrid-scan.pdf` 带已有标题，正文仍应能被识别，标题不重复。
8. **图片输出**：选择“导出页面图片”，核对每页 PNG/JPEG；选择“提取原始图片”，核对扫描 PDF 的内嵌图像。多张图片直接按页面整理模式导出 PDF。
9. **压缩**：分别选择结构优化和扫描图片压缩，查看实际输出体积。使用图片压缩时确认提示；需要文字可搜索时同时开启 OCR。结构优化应保留文字、书签及仍有效的内部跳转。
10. **方案和日志**：保存方案，切换参数后加载，再退出重开程序核对方案仍在；设置中的操作日志可筛选“PDF 工作台”，并查看操作结果。
11. **日志搜索与导出**：按输出文件名搜索，详情和 TXT 应包含输出路径、警告和错误；TXT/JSON 只导出当前筛选结果。清空前取消应保留记录，确认后刷新仍为空。
12. **折叠导航**：左上角“收起”将导航从 84px 收为 56px 图标栏，悬停可看功能名称；已加载的页面不丢失，重开后保留折叠状态。

界面已在 1120×720 和 1280×820 窗口检查；扫描复核使用独立工作区，缩略图区域滚动、确认输出按钮保持可见。

## 验收边界

- OCR 适用于正常方向的扫描页及占据较大页面区域的扫描图片；本轮没有加入自动纠偏、手写识别或复杂表格结构重建。识别准确率仍受源图清晰度影响。
- 图片压缩会将页面转换成图片，原链接、表单等交互会丢失；结构优化保留这些结构，但不保证每份 PDF 都变小。
- 取消会在页面或处理阶段边界生效，不会强制中断正在执行的单页原生识别；已完成的输出仍然可用。
- 本轮没有验证正式安装包的下载、安装、升级全过程；更新状态逻辑已通过回归。也没有新发布安装包。
- 以上是列明样例和边界的验证结果，不能代表所有外部 PDF 编码、损坏文件或扫描质量组合。

## 实现参考

使用官方 Tesseract 语言数据和现有 PyMuPDF 能力，没有复制参考工具箱的业务代码。OCR 重复文字处理遵循 [PyMuPDF 透明删改区域的文档](https://pymupdf.readthedocs.io/en/latest/page.html#Page.add_redact_annot)，只作用于临时识别层；原页不执行删改。
